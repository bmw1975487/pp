# RoomVision 1.0.1 diagnostics

В приложение встроен глобальный crash logger.

При необработанном Java/Kotlin исключении он сохраняет в private storage приложения:
- время сбоя;
- версию приложения;
- производителя/модель телефона;
- Android SDK;
- ABI;
- состояние Java heap;
- имя упавшего потока;
- полный stack trace;
- lifecycle-события текущего запуска.

После следующего запуска RoomVision автоматически открывает MAX (`ru.oneme.app`) с готовым crash-log в тексте сообщения. Пользователь выбирает чат и нажимает «Отправить». Если MAX не установлен, открывается стандартное Android-меню «Поделиться».

Android не разрешает стороннему приложению без участия пользователя молча отправить сообщение конкретному получателю в MAX, поэтому финальное нажатие «Отправить» остаётся за пользователем.
