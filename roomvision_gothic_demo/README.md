# RoomVision Gothic Demo 0.1

Android-демо: «выбрал мир → сразу включилась камера → комната показывается в выбранной стилистике».

Режим демо: **ГОТИЧЕСКИЙ ЗАМОК**.

Стек: JDK 17, Gradle 8.13, AGP 8.13.2, compile/target SDK 36, Build Tools 35.0.0, minSdk 29, Java 17, Camera2 + OpenGL ES 2.0. Без ARCore и без внешних runtime-библиотек.
