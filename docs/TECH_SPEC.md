# Техническое задание: PowerPoint 15 Colors

## 1. Результат

Один распространяемый файл `PowerPoint_15_Colors_Setup.exe`.

После однократного запуска он должен:

1. установить надстройку уровня приложения для настольного Microsoft PowerPoint на Windows;
2. зарегистрировать её как COM-надстройку PowerPoint;
3. включить автоматическую загрузку при каждом запуске PowerPoint;
4. добавить в ленту PowerPoint вкладку `ПАЛИТРА`;
5. показать 15 фирменных цветов в трёх командах: `Заливка`, `Текст`, `Контур`;
6. применить выбранный цвет к текущему выделению;
7. сохранить подробный установочный лог на рабочем столе и внутренний лог работы надстройки в `%LOCALAPPDATA%`;
8. самостоятельно проверить, что PowerPoint видит COM-надстройку и подключил её.

Пользователь получает только один EXE. Внутренние установленные файлы допустимы и создаются автоматически.

## 3. Архитектурное решение

Используется нативная для Office схема управляемой COM-надстройки:

- C#;
- .NET Framework 4.8;
- интерфейс `IDTExtensibility2` для жизненного цикла COM-надстройки;
- интерфейс `IRibbonExtensibility` для добавления RibbonX-интерфейса;
- регистрация сборки через системный `RegAsm.exe /codebase`;
- регистрация PowerPoint Add-in через `HKCU\Software\Microsoft\Office\PowerPoint\Addins\<ProgID>`;
- `LoadBehavior=3` — подключать и загружать при старте.

VBA, PPAM, программное изменение VBProject и VSTO не используются. Это исключает ошибки `AccessVBOM`, загрузки PPAM и зависимость от VSTO Runtime.

## 4. Один EXE

Один и тот же EXE выполняет две роли:

1. при запуске пользователем — установщик;
2. при COM-активации из PowerPoint — класс надстройки внутри той же .NET-сборки.

Установщик копирует себя в постоянный каталог, регистрирует установленную копию и после проверки позволяет удалить исходный загруженный EXE.

## 5. Установка

1. Проверить Windows, PowerPoint и разрядность Office.
2. Если PowerPoint открыт — показать окно с `Повторить` и `Отмена`, не завершаться молча.
3. Удалить только предыдущие версии этого проекта: старые PPAM, старые ProgID и старую COM-регистрацию.
4. Скопировать EXE в `%ProgramFiles%\DOMRF\PowerPointPalette\`.
5. Выбрать 32- или 64-разрядный `RegAsm.exe` по разрядности PowerPoint.
6. Зарегистрировать установленный EXE как COM-сборку с `/codebase`.
7. Создать ключ PowerPoint Add-ins и записать `FriendlyName`, `Description`, `LoadBehavior=3`, `CommandLineSafe=0`.
8. Запустить PowerPoint через COM, обновить коллекцию `COMAddIns`, подключить надстройку и проверить `Connect=True`.
9. Создать пустую презентацию, чтобы вкладка ленты была видна.
10. При успехе оставить PowerPoint открытым и показать сообщение `Установка завершена`.
11. При ошибке открыть лог и не показывать ложное сообщение об успехе.

## 6. Интерфейс PowerPoint

Вкладка `ПАЛИТРА` располагается после `Главная`.

На ней находятся три меню:

- `ЗАЛИВКА`;
- `ТЕКСТ`;
- `КОНТУР`.

В каждом меню — категории `Основные`, `Дополнительные`, `Статусные`, а внутри — 15 кнопок с цветными квадратами и HEX-кодами.

## 7. Применение цвета

### Заливка

- выделенные фигуры;
- группы фигур как выбранные объекты;
- фон контейнера диаграммы или другого выбранного shape, если PowerPoint допускает заливку.

### Текст

- выделенный фрагмент текста;
- весь текст выбранной фигуры;
- несколько выбранных текстовых фигур.

### Контур

- линии и контуры выбранных фигур.

Если подходящего выделения нет, показывается понятное сообщение, а PowerPoint не падает.

## 8. Логи

Установочный лог:

- `%USERPROFILE%\Desktop\PowerPoint_15_Colors_INSTALL_LOG.txt`.

Лог надстройки:

- `%LOCALAPPDATA%\DOMRF\PowerPointPalette\addin.log`.

Лог содержит этап, время, разрядность Office, путь RegAsm, коды завершения, состояние `COMAddIn.Connect`, исключение и stack trace.

## 9. Приёмочные критерии

Сборка считается готовой только если:

1. CI собирает один EXE без ошибок;
2. встроенный self-test подтверждает 15 уникальных цветов;
3. RibbonX XML является корректным XML;
4. XML содержит 45 команд применения цвета: 15 × 3 режима;
5. EXE успешно проходит режим `--self-test`;
6. установщик никогда не пишет `Готово`, пока не подтверждено `COMAddIn.Connect=True`;
7. при любой ошибке создаётся читаемый лог;
8. исходники, документация и сборочный workflow находятся в отдельной ветке `powerpoint-palette-addin`.

## 10. Ограничение PowerPoint

Надстройка добавляет собственную постоянную палитру на ленту PowerPoint. Она не заменяет и не удаляет встроенное системное окно цветов Microsoft, потому что штатный color picker PowerPoint не предоставляет API для внедрения произвольных элементов внутрь его списка.
