# План тестирования

## A. Автоматические проверки в GitHub Actions

### A1. Сборка

- восстановление зависимостей;
- сборка Release под `.NET Framework 4.8`;
- отсутствие предупреждений уровня error;
- наличие одного итогового EXE.

### A2. Self-test

Команда:

```text
DOMRF.PowerPointPalette.exe --self-test
```

Проверяет:

1. палитра содержит ровно 15 записей;
2. все HEX-коды корректны;
3. все цвета уникальны;
4. преобразование `#RRGGBB` в Office RGB корректно;
5. RibbonX — корректный XML;
6. в RibbonX присутствует вкладка `ПАЛИТРА`;
7. создано ровно 45 кнопок применения: 15 заливок, 15 цветов текста, 15 контуров;
8. у каждой кнопки корректный `tag`;
9. каждый callback, указанный в XML, существует как публичный метод COM-класса;
10. режим self-test завершается кодом 0.

### A3. Артефакт

Workflow публикует:

- `PowerPoint_15_Colors_Setup.exe`;
- `SHA256.txt`.

Пользователю передаётся только EXE.

## B. Установочные проверки на целевом компьютере

### B1. Чистая установка

Предусловие: PowerPoint закрыт.

Ожидается:

- запрос UAC;
- EXE копируется в постоянный каталог;
- RegAsm возвращает код 0;
- ключ Addins создан;
- PowerPoint открывается;
- `COMAddIns.Item(ProgID).Connect=True`;
- вкладка `ПАЛИТРА` видна;
- лог заканчивается `RESULT: SUCCESS`.

### B2. PowerPoint открыт

Ожидается:

- установщик не падает;
- показывает окно с просьбой закрыть PowerPoint;
- после закрытия и нажатия `Повторить` продолжает установку.

### B3. Повторная установка

Ожидается:

- старая регистрация удаляется;
- файл обновляется;
- новый экземпляр загружается;
- дубликаты надстроек не появляются.

### B4. Ошибка COM-регистрации

Ожидается:

- сообщение об ошибке;
- никакого ложного `Готово`;
- лог автоматически открывается;
- в логе есть команда RegAsm, exit code, stdout и stderr.

### B5. Ошибка RibbonX

Ожидается:

- `OnConnection` есть в add-in log;
- `GetCustomUI` записан;
- при ошибке XML установщик фиксирует отсутствие вызова `RibbonLoaded`;
- пользователю предлагается включить `Показывать ошибки пользовательского интерфейса надстроек` только как дополнительная диагностика, а не как способ установки.

## C. Функциональные проверки

### C1. Заливка

- одна фигура;
- несколько фигур;
- линия без заливки — корректное сообщение или допустимое применение;
- группа фигур;
- фигура с текстом.

### C2. Текст

- выделенный фрагмент текста;
- курсор внутри текста без выделения;
- выбранная текстовая фигура;
- несколько текстовых фигур;
- фигура без текста — пропускается, PowerPoint не падает.

### C3. Контур

- обычная фигура;
- линия;
- несколько фигур;
- фигура без видимого контура — контур включается и окрашивается.

### C4. Цвета

Каждый из 15 HEX проверяется по фактическому RGB после применения.

## D. Приёмка пользователя

1. Пользователь скачивает один EXE.
2. Закрывает PowerPoint.
3. Запускает EXE один раз.
4. PowerPoint открывается автоматически.
5. На ленте появляется вкладка `ПАЛИТРА`.
6. Цвет выбирается по цветному квадрату.
7. После перезапуска PowerPoint вкладка остаётся.
